# Скрипт автоматического исправления электронного дневника

Этот вспомогательный скрипт предназначен для исправления успеваемости выбранного ученика в [школьном электронном дневнике](https://github.com/devmanorg/e-diary/tree/master). Скрипт исправляет плохие оценки, удаляет замечания от учителей и добавляет случайную похвалу по выбранному предмету.

## Что делает скрипт

- **Исправляет оценки:** находит все двойки и тройки выбранного ученика и исправляет их на пятёрки.
- **Удаляет замечания:** полностью очищает историю замечаний указанного ученика.
- **Добавляет похвалу:** находит самый первый урок по указанному предмету в расписании класса и добавляет случайную похвалу от имени преподавателя.

## Требования к окружению

Перед использованием скрипта убедитесь, что:
- У вас уже развёрнут и запущен сайт [электронного дневника школы](https://github.com/devmanorg/e-diary/tree/master).
- Вы скопировали файл скрипта (`scripts.py`) и положили его в корневую директорию проекта дневника (где находится файл `manage.py`).

## Инструкция по запуску

Скрипт запускается напрямую через консоль сервера. При запуске обязательно нужно передать два аргумента: **Фамилия и Имя ученика** и **Название предмета**. 

> **Важно:** Если имя или предмет состоят из нескольких слов, обязательно оборачивайте их в **двойные кавычки `"`**, чтобы терминал воспринял их как один аргумент.

### Примеры использования:

- **Стандартный запуск:**
  ```
  python scripts.py "Васильева Полина" "Математика"
  ```

- **Вызов справки (узнать, какие аргументы ожидает скрипт):**
  ```
  python scripts.py --help
  ```
